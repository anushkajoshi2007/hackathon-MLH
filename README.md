# 🌍 AI Disaster Assistant

An AI-powered disaster risk assessment and emergency response prototype.

## 📌 Problem Statement

During disasters such as floods, earthquakes, fires, and extreme weather, people often lack timely and location-specific information.

This project uses machine learning to analyse disaster-related environmental and demographic data and predict the level of risk.

## 🚀 Features

- Disaster type selection
- Disaster risk prediction
- Low / Medium / High risk classification
- Disaster-specific input fields
- Emergency recommendations
- Interactive Gradio interface
- Random Forest machine learning model

## 🧠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Random Forest
- Gradio
- Google Colab

## 📊 Disaster Types

The system supports:

- 🌊 Flood
- 🌎 Earthquake
- 🔥 Fire
- 🌪️ Extreme Weather

## ⚠️ Important Note

This project is an AI prototype developed using simulated data.

The predictions are not intended to replace official disaster warnings or emergency services.
